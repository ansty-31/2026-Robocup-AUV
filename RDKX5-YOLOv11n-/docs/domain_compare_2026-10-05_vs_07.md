## 结论

1. **检测层面并没有"失效"**：三套的选中门 conf（0.83–0.87）、四角齐比例（75%–85%）都在同一水平，
   07/today 甚至比 05 更常给出四角齐的门。**所以"失效"不是"模型看不到门"**。
2. **低层"环境"（亮度/色偏/水下雾）几乎分不开**：与训练域的分布距离 05=55.6、07=55.5（today 反而最近 45.4）。
   单靠全局亮度/颜色无法解释 05 能用、07 不能用。
3. 真正可量化的差异是**场景构图与拍摄几何**，按差异大小排序：
   - **每帧门数**：训练域 1.35 → 05 2.26 → 07 **2.95**（07 的画面里同时有 ~3 个门，"选哪一个门"的压力是训练时的两倍多）；
   - **明暗梯度**：05 上下亮度差 −13，07/today −27/−31（画面里亮水面/反光更多、下方阴影更深），对比度 25→28→31；
   - **相机俯仰/构图**：水面交界行 05 在 0.659，07/today 在 0.79/0.75（画面包含更多水下结构）；
   - **门的距离**：选中门面积 05 166k（边长 ~408px）→ 07 121k → today **75k（~274px，门更远）**；
   - **门的高宽比**：05 1.44（≈训练域 1.46）→ 07 1.68 / today 1.61（看起来更"竖长"）；
   - **清晰度**：05 最锐（Laplacian 168），07 127，today 93（≈训练域 84，today 明显更糊）；
   - **05 之所以"顺"**：它的门**最近、最正、最清晰**——选中门内角偏差仅 4.8°（07 10.2°、today 8.8°），最小 v 0.94。
4. 因此，若 05 能用而 07 不能用，**最可疑的是"多门拥挤 + 更远的门 + 更强的明暗梯度"这三条叠加**（会先击穿下游的
   "选门 → PnP → 对门接近"环节，而不是检测本身）。需要知道具体失效现象才能继续收敛（见下）。
