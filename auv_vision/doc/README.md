# doc/ — 文档索引（三层分类）

| 目录 | 放什么 | 特征 |
|---|---|---|
| `设计/` | 参考型设计文档 | 描述**当前**设计与契约，跟着代码一起更新（如解码契约、总体算法说明、**过门逻辑树**） |
| `现场/` | 现场用材料与待办 | 到场照着做（现场卡）、或**尚未实现**的想法（待研究） |
| `记录/` | 记录与归档 | **不改写历史**：按天的改动全记录、现场步骤、导读写生、已结束的成篇文档 |

`注释历史.md`（本层）是**跨文件的索引**：代码/配置注释里搬出来的"实测数字 / 试错过程 / 参数沿革 / 注意事项"按文件分节收录；
2026-10-05 起正文按域拆到 `注释历史/` 目录（`cfg.md` · `gate.md` · `base-common.md` · `grab-task-manual.md` · `tools.md` · `tests.md` · `misc.md`），
索引（`doc/注释历史.md`）里给出对应表 —— 代码注释里的 `见 doc/注释历史.md` 仍然有效。
配套约定：
- **代码与 cfg 注释只写"是什么 + 当前值/单位"**（+ 阶段标识）；**注意事项与更改历史一律放这里**；
- 记录类文档（`记录/` 下按天写的那几份）**保持原样**，路径搬动也不回改正文（见 `记录/README.md`）；
- 同一事实不要在两处写两遍：设计→`设计/`，当天发生了什么→`记录/`，数值沿革→本文件。

**先读链**（README 为准）：`README.md` → `设计/算法说明.md` → **`设计/过门逻辑树.md`（过门逻辑的唯一入口）**
→ `记录/过门-状态机与参数.md`（**历史**逐状态导读 + §9 现场实测）→ `设计/gate_pose_decode_spec.md`（换 bin 必读）
→ `记录/实验待测-runbook.md` → `记录/2026-09-2X-改动记录-review.md`。
