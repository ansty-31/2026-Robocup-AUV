## 5. 任务算法要点

### 5.1 撞球（task1_2/ball.py）
运动链（视觉识别与运动逻辑都在本项目内，ball 权重为 bbox 检测）：

| 相位 | 下发 | 转移 |
|---|---|---|
| SEARCH | 脉冲旋转（spin/pause）+ 周期性慢速前进探测 | 见球 → CENTER |
| CENTER | **仅 yaw + heave**（surge=0、sway=0），水平+竖直居中 | 连续 `center_confirm_frames` 帧居中 → APPROACH |
| APPROACH | **分级前进 + 仅 sway**（yaw=0、heave=0） | 面积(EMA) ≥ `dash_ratio` 连续 `dash_confirm_frames` 帧 → DASH |
| DASH | `surge_fast`（分级最高速）恒速 `dash_dur_s`，**不检测是否撞到** | 计时到 → STOP |
| STOP | 全 0 保持 `stop_hold_s`（稳定停住） | → DONE(hit) |

丢目标沿用原阶梯：短时保持/惯性 → hold（原地全 0，`engage_hold_s`）→ 回 SEARCH；
**CENTER 段丢失绝不前进**。总时限 `comm.ball.timeout_ms`（DASH/STOP 期间不打断）。

### 5.2 过门（gate/，**扁平 v1.2**；完整设计见 gate-PnP 文档）
- keypoint（门 + 外轮廓四角 TL/TR/BR/BL）→ `solvePnP(IPPE)`+RefineLM → 6-DoF，深度 `Z=tvec.z`；
- 门 = 闭合矩形框（红 PVC，0.70×0.50 m，悬空），前后对称无朝向要求；
- 相位机 SEARCH→RANGE_ALIGN(GOLDEN/CREEP/HOLD/REACQUIRE)→APPROACH→THROUGH；
  降级链 full/p3p/width/coarse。
- **直冲出口（任一成立即 THROUGH：只前进、不做横向微调）**：
  ① 位姿可信且 `Z≤z.cross` 连续 `z.cross_confirm_frames` 帧（**实船已验证，勿动**）；
  ② 进近中已到近距(`Z≤z.near_lost_m`)后整门丢失；
  ③ **width 档**（只对向 2 角）：对准确认 + 偏差在安全带内 + `Z≤width.z_max` → 直冲；
  ④ **coarse 档**（角点不足、整框可信）：对准确认 + 框占比 ≥ `coarse.dash_ratio` → 直冲。
  ③④ 是低帧率(实测 8~11fps)+机身抖动下的懒人策略：**对准好就冲**、姿态交给下位机 PID，
  不叠加多帧高精度闭环。coarse 档仲裁原则 = **只有未对准才 HOLD/后退**（对准就 creep 靠近或直冲）。
- **过门计数**：THROUGH 内按 `through.confirm_frames` **帧数**计数 → `pass+1`；
  即"冲刺时长按帧算"，**低帧率下时间更长**（8~11fps ≈ 0.7~1.0s；30fps ≈ 0.27s）。
  达 `pass_target` → `DONE(pass)`（立即回中性，不再有额外前冲余量）——这条实测有效，暂不改。
- 角点逐点融合 `gate/kpt_memory.py`：**可选功能、默认开启**（= 周一 09-14 原行为）——关掉用 `enable: false` 或
  `AUV_GATE_KPT_MEM=0`，关闭时角点单帧直用（行为等同没集成该功能）。
- 配置健壮性：`gate_task` 所有 cfg 读取走 `_sub/_cfg/_num` 兜底，**缺键时用"等于当前 cfg 的默认值"**，
  `AUV_CFG_DIR` 指向缺新键的旧配置不会 AttributeError。

## 6. 串口协议（下发 11B / 上行 14B，与下位机对齐）

```
下发: 0xA5 | axis0..axis6 | btn0..btn2
axis0=yaw axis1=surge axis2=heave axis3=sway（中位128，极性>128 正向）
任务 → DOF → comm.yaml dof_map → 轴字节（ramp 平滑）；心跳≥20Hz；急停=中位锁定

上行: 0xAA 0x55 | depth_cm | target_cm | roll_cd | pitch_cd | yaw_cd | checksum
      (int16 小端 ×5，从 byte3 起；checksum = sum(前13B) & 0xFF；见 base/telemetry.py)
```

**限深保护（base 层唯一一处，任务不感知）**：每次发帧前读空接收缓冲 → 最新深度；
`comm.depth_guard` 判定 `depth ≤ min_depth_m`(默认 0.3m) 时本帧**禁止上浮**
（heave 清零 + heave 轴当帧回中 `snap`），surge/sway/yaw 原样——保护不干扰对准/前进；
遥测缺失或超时(`stale_ms`)按 `stale_action` 处理：`pass`(默认)放行 / `block_up` 连盲上浮也不许
（SIM 无串口始终放行）。手动模式(udp_server 键盘遥控)同样受此限制。
