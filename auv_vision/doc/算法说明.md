# 算法说明 — AUV 视觉项目（RDK X5）构建思路（v3）

> 总览与代码阅读入口；**gate 新架构设计与移植来源见 `算法说明-gate-PnP移植方案.md`**；用法见 `README.md`。

## 1. 平台与总体决策

| 项 | 决策 |
|---|---|
| 平台 | RDK X5（Ubuntu 22.04 arm64；`.bin` / march `bayes-e`） |
| 推理 | mock → hbm_runtime/pyeasy_dnn/onnx；**ball 与 gate 权重分离** |
| 相机 | 前视 USB 1280×720（已标定 RMS 0.705）；下视 IMX415 **保留**（素材/未来任务；策略不用） |
| 任务 | 一 撞球（前视，task1_2/ball.py）→ 记忆返回（task1_2/return_by_memory.py）→ 三 过门（gate/） |
| 编排 | 任务一 + 记忆返回由 `task1_2/run_ball_return.sh` 编排；`main.py` 状态机负责单任务（ball/gate） |
| 图像链路 | `common/preprocess.py`：去畸变→WB/CLAHE/gamma→640（共用，勿改） |

│   ├── preprocess.py  #   识别前图像链路
│   └── detector.py    #   DetectorHub（Det 可选 kpts；按任务注册）
├── task1_2/           # 任务一 + 记忆返回工具
│   ├── ball.py        #   任务一 BallTask（撞球）
│   ├── return_by_memory.py  #   记忆返回（撞球后回出发点）
│   └── run_*.sh       #   撞球+记忆返回编排（待机→下潜→前进→撞球(记轨迹)→回放→回退）

依赖规则：任务代码只 import `base`/`common` 与同级模块；`main.py` 为装配层
（注册 gate 后端、按 `comm.tasks.enabled` 组任务）。

## 3. 参数组织与图像链路

- `cfg/vision.yaml`：camera(front/down)、`image.*`、`model.*`（mode/path/labels/`task_models.gate`）、
  `gate.*`（几何/keypoint/PnP）、sim、debug；
- `cfg/comm.yaml`：serial/dof_map/心跳/急停/ramp/motion + `tasks.enabled` + `ball/gate`；
- 代码读 `S.vision.*`/`S.comm.*`；`AUV_CFG_DIR`/`AUV_VISION_CFG`/`AUV_COMM_CFG` 可切配置；
- 训练/推理同域（ball 已验证）：训练图经同一 `undistort+enhance+640`；`common/preprocess.py` 不改。

## 4. 状态机与编排

```
IDLE ──► [BALL ──► GATE] ──► DONE          （main.py，按 tasks.enabled）
撞球真机流程（task1_2/run_ball_return.sh）：
  待机 → 下潜 → 前进 → main --task ball(AUV_DOF_LOG 记轨迹) → return_by_memory(反向回放) → 回退
```
- `main.py --task ball|gate|all`；`all` 按 `comm.tasks.enabled`（默认 `[ball]`）执行；
- gate 需后端：`model.mode=mock` → MockGateBackend；否则 `model.task_models.gate.path`（.bin）。

## 5. 任务算法要点

### 5.1 撞球（task1_2/ball.py）
面积占比分级调速 + 视觉居中 PID + 智能搜索（旋转脉冲/慢速探测/超时停）。

### 5.2 记忆返回（task1_2/return_by_memory.py，撞球后回出发点）
- 不依赖视觉（下视相机保留，策略不用）：撞球时把实际发出的每帧运动写入轨迹
  （`AUV_DOF_LOG=/tmp/path.csv python3 main.py --task ball`）；
- 返回 = 时间对称反向回放（方向取反、顺序颠倒），`--extra-sec` 加保险余量；
- 纯航位推算，受水流/打滑影响有偏差。

### 5.3 过门（gate/，新；完整设计见 gate-PnP 文档）
- keypoint（门 + 外轮廓四角 TL/TR/BR/BL）→ `solvePnP(IPPE)`+RefineLM → 6-DoF，深度 `Z=tvec.z`；
- 门 = 闭合矩形框（红 PVC，0.70×0.50 m，悬空），前后对称无朝向要求；
- 相位机 SEARCH→RANGE_ALIGN(GOLDEN/CREEP/HOLD/REACQUIRE)→APPROACH→THROUGH；
  完成判据 = 机身过门（`Z≤z.cross` 后目标消失确认）；降级链 full/p3p/width/coarse。

## 6. 串口协议 v2（11B，与下位机对齐）

```
帧: 0xA5 | axis0..axis6 | btn0..btn2
axis0=yaw axis1=surge axis2=heave axis3=sway（中位128，极性>128 正向）
任务 → DOF → comm.yaml dof_map → 轴字节（ramp 平滑）；心跳≥20Hz；急停=中位锁定
```

## 8. 部署与模型

1. 训练：ball 沿用；gate 用 keypoint 数据集（外轮廓四角，允许只标可见角）；
2. 转换：`.pt → ONNX → OE makertbin(.bin)`，填 `model.task_models.gate.path`；
   **.bin 导出后先做 keypoint 解码自检（设计文档 §6）**；
3. 打包：arm64 deb → 镜像 `/app/auv_vision`。
