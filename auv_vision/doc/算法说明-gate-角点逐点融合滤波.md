# gate 角点逐点融合滤波 — 数据处理说明（代码 `gate/data/kpt_memory.py`）

> 本文说明 v1.2 新增的**门角点数据处理层**：在识别之后、位姿解算之前，对**每个特征点
> 自身**做鲁棒自适应融合滤波，用来抑制水面倒影引起的小漂移 / 短消失 / 偶发鬼点，
> 让状态机保持稳定。
>
> 命名说明：这一层在讨论里被叫作 "kpt_gate"，落地的模块名是 **`gate/data/kpt_memory.py`
> （类 `KptMemory`）**，配置段 `vision.gate.kpt_mem`，调用点在 `gate/gate_task.py::_step`。
>
> 定位一句话：**它是一次"融合滤波"**——准确说是
> **逐点鲁棒自适应 α-β 融合滤波（robust adaptive α-β fusion filter），带残差尺度验证门
> (validation gate)、滑行 (coasting) 与航迹质量衰减**；不是简单平均，也不是卡尔曼/联合滤波。

---

## 1. 边界：改了什么、没改什么

| | 内容 |
|---|---|
| **没改** | 识别模型与推理链路；`parse_kpt_mode` 的 mode 判定逻辑；`gate_pose` 的 PnP 解算与消歧；门几何/降级链/相位机 |
| **改了** | 只在 `det.kpts / det.kpt_conf` 上做逐点数据处理，输出**同样形状**的 `(4,2)` 像素 + `(4,)` 置信度 |
| **调用链** | `gate_task._step()`：`det` → `KptMemory.update(kpts, kpt_conf, now_ms)` → `parse_kpt_mode(...)` → `gate_pose(...)` |
| **开关** | `vision.gate.kpt_mem.enable: false` → 完全旁路，回到"单帧直用"的原始行为 |

## 2. 问题：现象 → 根因 → 为什么要修在数据层

实船水池现象：门框上端靠近水面时出现倒影 → ①角点小范围漂移 ②角点短时消失
③偶发角点"打到倒影上"。识别本身（肉眼）够用，但误差**不稳定**，于是：

```
角点抖动/短消失 → 当帧"有效角点数"在 4/3/2 之间跳
                → parse_kpt_mode 的 mode 在 full↔p3p↔coarse 抖动（实测翻转 51~85 次/400 帧）
                → 位姿时有时无 → 状态机 GOLDEN↔HOLD 抖
                → coarse 且门框占比 > coarse.near_ratio → REACQUIRE → 表现为"一直在对准、还后退"
```

**触发后退的直接原因是"点不全"，而"点不全"的根因是倒影**。因此修在**点的数据层**，
而不是去压制后退（压制会扼制运动逻辑本身）；同时**不做硬剔除**——信息本来就只有 4 个点，
滤严了状态机会更容易瞎。

## 3. 方法：逐点鲁棒自适应 α-β 融合滤波

每个角点 `i` 独立维护 5 个量：融合位置 `p_i`、速度 `v_i`、置信度 `c_i`、残差尺度 `σ_i`、缺失计数。

### 3.1 一帧的流程

```
dt   = clamp(now - t_last, 1ms, 500ms)
pred = p_i + v_i·dt                        # ① 匀速外推（补滞后）
R_i  = clip(k_sigma · σ_i, r_min_px, r_max_px)      # ② 验证门半径（来自该点历史分布）
d    = |x_i - pred|                        # ③ 残差（当帧观测 vs 预测）
w_geo= 1 / (1 + (d/R_i)²)                  # ④ 柯西鲁棒权重（连续，无跳变）
w    = clip(w_prior_i · w_geo, 0, 1)       # ⑤ 证据权重 × 几何一致性
       w_prior_i = 质量分**先验** = conf_i^pow · q_time(帧龄)（gate/data/quality.py 给；
                   不给质量分时 w_prior = conf_i，与升级前逐位一致）
（可选 w_min>0：w 低于它就彻底忽略这一帧；默认 0 = 纯软融合）

gain = q_gain_floor + (1-q_gain_floor)·q_mem   # ⑥a 帧级增益（q_mem=历史位姿证据 EMA）
a    = alpha · gain · w                        # ⑥b 增益被"帧质量 × 点质量"调制
p_i  = pred + a·(x_i - pred)               #    位置融合
v_i  = v_i(1-βw) + βw·(p_i-pred)/dt        #    速度融合（限幅 ±5 px/ms）
c_i  = (1-a)·c_i + a·conf_i                #    置信度融合（连续）
σ_i  = (1-λ)·σ_i + λ·max(d, σ_floor)       # ⑦ 残差尺度慢跟踪 → 半径自适应
```

**没打到**（`conf_i < conf_floor`）：`p_i ← pred`；
近期见过（`≥min_frames` 帧且 `≤valid_ms` 且缺失 `≤max_missing_frames`）→ `c_i ← max(c_i, recall_conf)`（滑行）；
否则 `c_i ← c_i·(1 - conf_decay)`（衰减，最终自然低于 `keypoint.conf_thr` 而被原逻辑剔除）。

### 3.2 每个环节对应的标准术语

| 实现 | 术语 | 效果 |
|---|---|---|
| `α-β` 递推（位置+速度） | α-β 滤波 / g-h 滤波（匀速模型，稳态等价卡尔曼） | 抑噪；带匀速补偿 → **零稳态滞后** |
| `w = w_prior × w_geo` | 置信度加权的**鲁棒 M 估计**（IRLS 权重） | 不可信的观测"少信"而不是"丢弃" |
| `w_prior = conf·q_time` | 质量分**先验**（帧新鲜度进了权重） | 过期/低置信帧少拉，但点仍有效 |
| `gain = f(q_mem)` | 质量分**帧级**增益（历史位姿证据 EMA） | 位姿链最近不可信 → 更信历史、更平滑（有下限） |
| `w_geo = 1/(1+(d/R)²)` | 柯西/Lorentzian 权重函数 | 连续平滑，无二值跳变 |
| `R = k_sigma·σ` | 由残差尺度得到的**验证门**(gating) | 挡住远离本点轨迹的观测（倒影鬼点） |
| `σ` 慢跟踪残差 | 稳健尺度估计（类 MAD） | 半径随该点"平时有多飘"自动伸缩；世界真变了能**自愈** |
| 只预测不更新 | **滑行** (coasting) | 短消失期间状态不丢 |
| `c_i` 衰减 | 航迹质量分/置信度衰减 | 长丢失时交给原判定逻辑自然降级 |

### 3.2b 质量分的两个入口（v1.4）

`gate/data/quality.py` 给出的两路"证据质量"是本层的**可选**输入，缺省时行为与升级前一致：

| 入口 | 来源 | 作用位置 | 语义 |
|---|---|---|---|
| `w_prior[i]` | 原始角点 conf × 帧新鲜度（**先验**，不看位姿） | 取代 ⑤ 里的 `conf_i` | 这一帧**这个点**值多少权重 |
| `q`（用 `q_mem`） | 后验总分的 EMA（**历史**位姿证据） | ⑥a 帧级 `gain`，乘在 α/β 上 | 这一帧**整体**该多信观测 |

两路都**只调权重、不做硬判**：帧差只会"少拉"，点仍有效、状态不丢，与本节
"不硬判无效"的原则一致。

### 3.3 三条关键设计取舍

1. **软融合替代硬门限**：不做"有效/无效"二值判定，**始终输出融合状态+连续置信度**。
   于是单帧鬼点只会让权重→0（对融合点几乎无影响），**却不会把该点打空** ——
   这就是"稳状态机"和"不把点滤没"能同时成立的原因。
2. **半径来自该点自身历史分布**（而不是固定像素阈值）：点安静 → 半径小（鬼点一冒头就被压权重）；
   门快速逼近 → 帧间位移大 → σ 变大 → 半径自动放大（**不会把真点误判成鬼点**，
   也不会像固定阈值那样"残差永远偏大 → 永久失效"）。
3. **零滞后优先**：不做窗口算术平均（那会把 `Z` 拖后、过门判据偏晚），
   α-β 的匀速补偿把"平均的抑噪"和"不滞后"同时拿到。

## 4. 参数（`cfg/vision.yaml → gate.kpt_mem`）

| 键 | 默认 | 含义 / 调参方向 |
|---|---|---|
| `enable` | true | false = 旁路，回到原始行为（便于水面 A/B） |
| `alpha` | 0.4 | 融合增益。**调大→更快、更抖**；调小→更稳、更迟 |
| `beta` | 0.1 | 匀速补偿增益。跟踪加速运动时调大 |
| `k_sigma` | 3.0 | 半径 = k_sigma×σ。**调小→更不信偏离大的观测**（更稳）；`≤0` 关闭几何权重（退化为纯 α-β） |
| `r_min_px` / `r_max_px` | 10 / 80 | 半径限幅。`r_max_px≤0` 亦表示关闭几何权重 |
| `sigma_init_px` | 8.0 | σ 初值（冷启动时的半径） |
| `sigma_lambda` | 0.15 | σ 慢跟踪速率。调小→历史更长（更稳、适应更慢） |
| `w_min` | 0.0 | >0 时把权重低于它的帧彻底忽略（恢复"硬关"）；0 = 纯软融合 |
| `conf_floor` | 0.05 | 低于它视为"本帧没打到（缺失）" |
| `recall_conf` | 0.55 | 短消失回忆时给的最低置信度（应 ≥ `keypoint.conf_thr`） |
| `conf_decay` | 0.35 | 长丢失时置信度衰减率 |
| `max_missing_frames` | 5 | 连续缺失多少帧内还"回忆"（≈ 0.5s @10fps） |
| `min_frames` | 2 | 至少见过几帧才允许回忆 |
| `valid_ms` | 800 | 多久没见到就不再算"近期见过" |

**想更稳**：`alpha↓`、`k_sigma↓`、`sigma_lambda↓`、`max_missing_frames↑`
**想更快**：`alpha↑`、`k_sigma↑`、`sigma_lambda↑`、`w_min>0`（对可疑帧更果断）

## 5. 实测性质（`python3 tests/test_gate_kpt_memory.py`，13 项）

| 指标 | 结果 |
|---|---|
| 抑抖动（静止 + 6px 噪声） | 输入 σ≈6.0px → 输出 **σ=2.4px** |
| 匀速运动稳态滞后 | **−0.54 px**（几乎不滞后 → 不影响过门判据） |
| 单帧鬼点 300px | 融合点只动 **0.11 px**，且该点**仍有效**(conf=0.90) |
| 对照：关掉几何权重 | 同一帧被拽走 **114 px**（说明旋钮确实在起作用） |
| 半径自适应 | 安静 **R=10px** vs 大漂移 **R=80px**（限幅生效） |
| 短消失（连丢 3 帧） | conf 保持 **0.90**（不触发降级） |
| 长丢失 | conf 衰减到 **0**（照常降级，不瞎编） |
| 角点真平移 120px | 最终偏差 **0.00px**（自愈，不会永久锁死） |

**端到端（合成"抖动+随机丢 1~2 角点"的进近，`gate_task` 全链路）：**

| 丢点率 | 记忆 | full 帧 | **mode 翻转(full↔非full)** | 退帧 | 结果 |
|---|---|---|---|---|---|
| 0.20 | 关 | 132 | **51** | 24 | ✗ |
| 0.20 | 开 | 157 | **5** | 24 | ✗ |
| 0.35 | 关 | 94 | **69** | 24 | ✗ |
| 0.35 | 开 | **173** | **0** | **0** | **✓ pass** |
| 0.50 | 关 | 73 | **85** | 24 | ✗ |
| 0.50 | 开 | 162 | **3** | 24 | ✗ |

> 结论：**状态翻转降一个数量级**（51→5 / 69→0 / 85→3），full 帧 +20~80%。
> 表中"✗"档位是**合成 mock 的固有特性**（mock 的门不理会我们的后退，800ms 后退期间
> 它自己飞过 0.7m 就再也不会出现），并非本层的问题；真船后退会增大距离，不会这样。

## 6. 与其他做法的对比（为什么不是它们）

同一组指标（静止+6px 噪声 / 匀速 0.6px 每帧 / 阶跃 +60px / 单帧鬼点 +300px / 每 10 帧丢 5 帧）：

| 做法 | 抖动 σ | 匀速滞后 | 阶跃延迟 | 单帧鬼点 | 短消失保持 |
|---|---|---|---|---|---|
| 无处理（单帧直用） | 5.3 px | 0 | 0 帧 | **被直接采用（误差 300px）** | 0% |
| 窗口算术平均 800ms | **1.8 px** | **−2.4 px（滞后）** | 8 帧 | 被采用（误差 33px） | 40% |
| α-β + **固定**像素阈值（旧实现，已弃） | 3.4 px | −0.45 px | 9 帧 | 拒绝✓（但会把真点也判无效） | 50% |
| **本方案**：α-β + 自适应验证门 + 软权重 | **2.4 px** | **−0.54 px** | 7 帧 | **位移仅 0.27px，且该点仍有效** | **60%** |

- 抖动：窗口平均最好，但代价是 2.4px 的**稳态滞后**（换算到深度：z=2m 时约 0.24m，
  足以让近距过门判据走错分支——这正是被换掉的原因）；本方案在**零滞后**前提下把 σ 压到 2.4px。
- 鬼点：窗口平均/纯 α-β 会把它吃进平均（误差 33~120px）；旧固定阈值虽然拒绝，但会连真点一起
  **判无效**（快速逼近时永久失效）；本方案把它降权到 ≈0（位置几乎不动），**而该点仍然有效**。

**本次刻意没做的**：宽高比/平行度/凸性等**几何结构约束**（信息量只有 4 点，怕过严滤除；
若日后要做，会做成"可关、可调、宽松"，且只做软权重、不做硬剔除）；
**联合滤波/位姿滤波**（把 4 点或整个位姿一起滤）——那是更大的一步，需要另立设计。

调参时建议先只看叠加里的两个量：
- `kpt`（融合后有效角点数）与 `kpt_raw`（当帧原始有效角点数）——**`kpt` 明显大于 `kpt_raw`
  说明正在靠融合/回忆撑住状态**；若 `kpt` 也掉到 3 以下，说明是真丢失（该降级就降级）；
- `mode` 的翻转频率 —— 这是"状态机稳不稳"的直接指标。
