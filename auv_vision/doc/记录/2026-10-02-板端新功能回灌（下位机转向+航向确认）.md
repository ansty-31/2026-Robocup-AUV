# 2026-10-02 板端新功能回灌本地（旋转交下位机执行 + 冲刺前航向确认锁存）

> 背景：本地仓库一度落后于板端。当天把板端工程拉下来逐文件比对，发现两处**本地从来没有过**的新功能，
> 已按用户决定回灌（"保留板端的新功能，本地也追上"）。本文记的是**改了什么、为什么、验证到什么程度**。
> 逐段判据仍以 `doc/设计/过门逻辑树.md` 为准；协议细节见 `doc/设计/算法说明.md` §6。

## 1. 新功能 A：旋转改由下位机执行（上位机不再 PID 闭环）

板端先行的模型：上位机不再读 yaw 遥测跑 PID，而是**发"相对角 + 编号"给下位机 → 按同一编号重发 → 等完成反馈**。

| 文件 | 变化 |
|---|---|
| `base/hw/uart.py` | 新增 `encode_turn_angle()`（-180..180 → 0..32767）、`build_turn_frame(角, 编号)`（执行位置 1 + 编号在 byte10）、`build_turn_cancel_frame(编号)`（编号 0 = 同步并取消）；新增下发/重发/等完成/取消的状态机（`request_turn` / `poll_turn_complete` / `cancel_turn`，100 ms 重发同一编号）；急停时发 cancel(0)；DOF 帧按钮载荷 `[0, 0, btn_values[2]]` |
| `base/hw/telemetry.py` | 上行帧 **14B → 15B**：`byte2` 由"保留"变 **turn_id**、新增 `byte13` = **turn_done**、校验位移到 `byte14`；`decode_telemetry` 返回 7 元组；`Telemetry` 新增 `turn_id/turn_done/turn_complete/begin_turn()` |
| `common/motion/turn_deg.py` | `TurnCore` 重写：`step(now_ms, uart)` → `request_turn()` → 等 `poll_turn_complete()`；收场只有 **DONE / TIMEOUT(completion_timeout) / ABORTED(send_failed·external)**；**删除**上位机 PID、方向自证、满舵无进展保护（那三条是闭环时代的兜底） |

**后果（已在文档与图里写明）**：整次转向在**同一帧内**跑完（自包含）；上位机 yaw 恒 0；
`action=hdg` 不再出现在逐帧记录里（收尾那一帧就改回 `center`），排查要看 `turn_log` 的 `gate_start/gate_loop/gate_stop_hard`。

## 2. 新功能 B：冲刺前"航向已确认"锁存 `_hdg_ok`

用户定的语义：**第一次看到 4 个角点的那次测量信息最全，就信那一次、也只信那一次**。

- 新增每门锁存 `_hdg_ok`（`gate_task.py` 初始化、`channels.py` 换门清零）。
- 置真只有两条路：① 有效 full 帧且 `|ψ| ≤ through.require_align_deg`（`modes.py`）；
  ② 下位机**回报转向完成**（`hdg.py`，`state == "done"`；超时/GIVEUP/ABORTED **不算**）。
- 转完即 `_hdg_done = True` ⇒ **一门只下一次转向**（"逐小步逼近"与 `hdg.max_turns` 退化为兜底配置）。
- 闸门读数从"最近一次 ψ"改成读锁存 ⇒ **从未测到 ψ 就永远不放行**（比旧行为更严）。

## 3. 回灌后测试暴露的两个"机制被新模型废掉"的问题（已修，属设计缺陷）

| 问题 | 机理 | 修法 |
|---|---|---|
| **门口超时兜底冲不出去** | 闸门原先两条出口共用 ⇒ width/coarse 档没有 PnP、永远没有 ψ ⇒ 兜底也永远被拦，卡在门口到任务超时 | `_start_through(bypass_hdg=True)`：**两条出口互相独立**，兜底自己已有"在门口+安全带+时长"三重条件，不再看航向（用户 2026-10-02 定） |
| **"转完反向平移"窗口一出世就被清掉** | 整次转向在同一帧内跑完 ⇒ 窗口开启那一帧的检测是**转向之前**采的（门还在视野里）⇒ 首帧就满足"门回来了"而退出 | 记录窗口开启帧号 `_post_sway_frame0`，**只认开启之后的新一帧**检测（`channels.py`） |

## 3.5 转向的两条入口都要有（用户 2026-10-02 补要求）

板端模型只留了"自动接受"那条路（gate 用 ψ 当目标角），而 **手动规定目标角度** 的入口被换模型时打断了：

- `turn_deg.py` 的 `main()` 只留 `--deg/--dir/--timeout` ⇒ `task1_2/run_ball_reverse.sh` 仍按老写法传
  `--out-max/--kp/--kd/--norm-deg` ⇒ **argparse 直接报 unrecognized arguments**（手动那条路就"没了"）。
- 退出码语义也变了（旧 0/3/4/5/6 → 新 0/3/5）。

修法：**两条入口都保留、共用同一个 `TurnCore`**：
1. CLI 恢复成"手动给角度"的正式入口，且**只暴露 `--deg/--dir/--timeout`**（用户定：其余运动参数都归下位机）；
2. 旧 PID 旋钮**不再接受**（传了直接 argparse 报错）—— 静默忽略会让人以为"设了限幅其实没设"，
   宁可让老脚本当场失败；`run_ball_reverse.sh` 里对应的 `AUV_TURN_YAW/KP/KD/NORM` 旋钮一并删除；
3. `run_ball_reverse.sh` 的措辞与退出码分支改到新模型（3=没等到完成反馈、5=下发失败/中止；6 标为旧模型遗留）；
4. 新增 3 条用例钉住手动入口：给角度 ⇒ 下发对应符号的角度（左=负/右=正）；只认三个参数，
   旧旋钮必须**报错退出（码 2）且不下发任何转向**。

## 4.5 配置清理：只留"生产真的会读"的参数（用户 2026-10-02 定）

新模型下"上位机只发目标角度"，于是把只服务旧闭环/只服务虚拟测试的参数一并删掉：

| 删除 | 理由 |
|---|---|
| `comm.motion.turn_pid`（kp/ki/kd/out_max/deadzone_deg/norm_deg/div_deg/sat_max_s/sat_progress_deg/overshoot_tol_deg） | 上位机 PID 驱动转向的那一套已整块删除（旋转交下位机）；代码里的 `_D_TURN_PID`/`turn_cfg()` 同步删除 |
| `comm.frame.btn_count` | 生产代码零引用 |
| `comm.motion.presets.{forward_fast,forward_slow,backward,left,right,up,down,turn_left,turn_right,search}` | 生产只用到 `stop`（`main.py` 收口）；其余只有测试在读 ⇒ 连同测试一起改掉 |
| `TurnCore(cfg=…, imag_sign=…, wait_tel_s=…, tag=…)` | 旧闭环遗留形参，没人读 |
| `HeadingAligner.imag_sign` + `last_info["img_sign"]` | 极性不再是上位机参数（转向不靠 σ） |

**挪位置**（不是删）：等"下位机完成反馈"的轮询节拍原属 `motion.turn_pid.period` ⇒ 改到 `comm.gate.hdg.turn_period = 0.05`（上位机自己的 pace）。

**保留**（不是测试专用）：`gate.hdg.max_turns` —— `_hdg_turns_full()` 仍在起转判据里被调用，
且 `tools/check/boat/check_hdg_lockup.py` 与 `tests/_bite_probe.py` 都钉着它（2026-09-27"疯狂旋转"的安全闸）。

## 4.6 撞杆后的收紧：门口不许盲冲（2026-10-02 晚）

- 现象：实船**撞杆**。原因是当晚加的"贴脸（框占比 ≥ 0.85）就直冲"—— 门框占满画面时**框心早已
  跑出画面**，`|dx|` 峰值 0.54（见 `log/gate_two_1002-0.jsonl` 段 379–529），"占比大"并不等于"对准"。
- 定案：**删掉"贴脸直冲"与"新鲜位姿直接 commit"两条**，改成：
  · 到门口但**本帧没位姿**（coarse/width）+ 新鲜位姿（≤ `loiter.pose_fresh_ms`=1000ms）判到门口
    ⇒ **转 REACQUIRE 后退重取**拿信息（连续 2 次拿不回来 ⇒ 原地保持，宁可不冲）；
  · 信息回来（位姿恢复且 `z ≤ z.cross` 连续 2 帧）⇒ 走正常 z 出口才 THROUGH；
  · 门口兜底原判据（占比 + |dx|/|dy| + `timeout_ms`）**不变**。
- 保留：`z.relock_away_m=2.0`（丢门重锁时 2 m 开外判"不是当前门"）。
- cfg：删 `loiter.inside_ratio/inside_ms`，留 `loiter.pose_fresh_ms`。
