### 居中判据 `align.*`（D 域）
- 2026-09-26 · `align.confirm_frames` 4 → **2**（用户：居中稳定 2 帧就转；水下水波复杂、画面难维持稳定）。
  原因：新模型下 `mode` 每帧在 full/coarse 间跳，实测 144 帧 ALIGN 里**一次都没攒到 4 连帧** ⇒ 正航向永远起不来。
  代价：抗单帧抖动变弱 —— 用 `px_*` 收紧来补。
- 2026-09-26 · `align.px_x/px_y` 0.20/0.25 → **0.10/0.12 → 0.10/0.15**（用户："很快进 fast，把居中阈值缩小一点"）。
  依据（板端 `log/gate_one_2026092.jsonl`）：居中达标那一帧实测 **dx=-0.079 / dy=-0.167** ⇒ 旧阈值等于"带着超限的偏就进 fast"。
- 2026-09-18 · 更旧的沿革：0.30/0.26 → 0.25/0.26 → 0.20/0.25。
- **2026-10-07 · 分档 + 纵向零点 + "机身稳"（并行）**：
  `_aligned(dxn, dyn, node, kx, ky)`（`channels.py`）= 各档自己的带（位姿档 `align.px_x/px_y`、
  width `width.align_x/align_y`、coarse `coarse.align_x/align_y`），档位节点缺键时回退到 `align`；
  `dyn` 在**算它的三处**统一减 `align.dy_target`（纵向零点，全局测量约定）。
  转向前置条件从"只有 align"改成 **`align ∧ 机身稳`**，两者**并行**数 `confirm_frames` 帧
  （串行 5+5 = 10 连续帧，实测窗口恒为 0 ⇒ 永不起转）。
  "机身稳"读**遥测**：`|Δroll|,|Δpitch|,|Δyaw| ≤ hdg.body_delta_max_deg(1.0)`（无遥测 fail-open）。
  依据：起转那帧（f17）|Δtyaw|=0.13°、|Δtrol|=0.24°、|Δtpit|=0.09°（全在中位以下）而 |Δψ|=26.4°
  ⇒ 那次起转是**图像 ψ 的噪声**推出去的，机身其实是静的。

### SWAY_BACK（ALIGN 子状态：转完反向平移）
- 2026-09-27 · 用户定：判"这算不算刚丢的那个门"分两级 —— ① **优先用距离**：|本帧新鲜 z − 转走那刻的 z| ≤ `post_sway_same_z_m`；
  ② **z 拿不到时才退回框占比**（用户原话：如果 z 一直被"新鲜帧"卡着，就相信框占比）：本帧占比 ≥ `post_sway_far_ratio` × 转走那刻的占比，
  **不得小于原 70%**（暂定 0.7）。z 拿不到 = 当帧 coarse / 唯一那次位姿已超 `z_stale_ms` / 转前没测到过 z。
- 同轮 · 本帧没检出 ⇒ 永远不算"门回来了"（继续推，由**到期判据**兜底，不会永久停摆）。

### 冲刺前航向闸门 `through.require_align_deg`
- 2026-09-26 新增（用户定）：最近一次测到的 psi（`_hdg_deg`）必须 ≤ 它才允许进 THROUGH（≤0 = 关闸）；
  三个出口（z≤cross / 近距丢门 / loiter）都要过。依据：那趟 19.2 s 日志里 psi=+30.6° 就冲了。
- **2026-10-07 · ψ 先平滑再比 tol（不放宽 tol）**：新增 `hdg.psi_ema_frames=10`，
  判据与目标角都用**慢 EMA**，快 EMA(≈4 帧) 只留日志字段 `hdg_fast`。
  依据：ψ 的帧间跳 7.8° 是真实航向(`tyaw`)帧间跳 0.33° 的 **24 倍** ⇒ 那段是噪声主导，

唯一构造入口（gate_task 与 preview_detect 共用），保证"关掉"时两边行为一致。

**设计原则**（按使用要求收敛）：
* **不硬判无效**：每个角点始终输出"融合后的状态"（位置 + 连续置信度），
把"信不信这一帧"变成权重的连续变化，而不是"有效/无效"的二值切换 ——
这样状态机不会因为单点抖动而翻来覆去（少掉 full↔p3p↔coarse 的抖动），
也不至于把信息量本来就不多的 4 个点滤没了。
* **逐点自身信息融合**：各角点独立维护 位置/速度/置信度/残差尺度，
σ_i 是该点残差分布的尺度（残差慢跟踪，会自适应：点安静→半径小；
* **软几何权重**：w_geo = 1 / (1 + (d/R)²)（柯西权重，越小越不可信，连续无跳变）；
一帧鬼点（d ≫ R）权重≈0 → 对融合几乎无影响，但**该点仍然有效**、状态不丢。
* **不影响速度**：α-β 时间加权平均带匀速补偿（稳态滞后≈0），不做窗口算术平均，
不引入额外确认延迟。
* **短消失回忆 / 长丢失衰减**：短时没打到 → 用融合状态外推并保持 recall_conf；
连续缺失超限或超 valid_ms → 置信度按 conf_decay 衰减，最终自然低于 keypoint.conf_thr，
让 mode 照常降级（不瞎编）。
全部参数可调（`vision.yaml → gate.kpt_mem`）。**本功能是可选开关，默认开启**（= 周一 09-14 原行为）：

`enable=false` 或 `AUV_GATE_KPT_MEM=0` = 角点单帧直用，与没集成本功能时逐字节同行为。
开关判定见 `kpt_mem_enabled()`，构造统一走 `build_kpt_memory()`（关闭时返回 None）。
